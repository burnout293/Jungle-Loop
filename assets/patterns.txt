# Jungle Loop : les groupes de pièces, dessinés à la main.
#
# Pour en ajouter un : une ligne « = nom », puis le dessin, une ligne de texte par rangée.
#   o   une pièce                 .   rien (ou un espace)
#   y   gemme jaune (5 pièces)    r   gemme rouge (10)    b   gemme bleue (20)
# Chaque caractère vaut 1,1 m de large et de haut. La rangée du bas se ramasse en courant.
# « = nom, base 3 » remonte tout le dessin de 3 rangées.
# Le jeu ne pose un dessin que si son sommet est atteignable : 5 rangées à pied,
# 9 avec le Double saut, 13 avec le Vol. 14 rangées et 40 colonnes au plus.
# Sans le Vol, un dessin peut aussi apparaître haut dans le ciel, hors d'atteinte : c'est l'envie de l'avoir.
# Les lignes qui commencent par # sont ignorées. Recharge la page pour voir tes changements.
