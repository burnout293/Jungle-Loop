# Jungle Loop

Course infinie en pixel art : tu as volé la relique du temple, et la jungle ne te laissera pas partir.

Le jeu est un site statique, sans compilation : ouvrir `index.html` derrière n'importe quel serveur web suffit.
Sur téléphone, il se joue en paysage et peut s'installer sur l'écran d'accueil.

- `js/` : règles (`game.js`), dessin (`render.js`), écrans (`main.js`), boutique et sauvegarde (`save.js`)
- `assets/` : images et musiques
- `tools/` : scripts qui découpent les planches d'images
- `mockups/` : maquettes
