# Jungle Loop — les Courses du jour : toutes les courses possibles.
#
# Chaque jour, le jeu tire une de ces courses grâce à la date : la même pour tout le monde, sur la même route.
# On peut la rejouer autant qu'on veut ; chaque palier ne paie qu'une fois par jour, au premier passage
# (atteindre l'Or donne aussi le Bronze et l'Argent).
#
# ─── GUIDE : créer ou modifier une course ───────────────────────────────────────────────────────────────────
#
# Une course commence par une ligne « [course] » suivie de son nom, puis des lignes « clé | valeur ».
# Seules « texte », « objets » et « paliers » sont obligatoires ; les autres changent les règles.
#
#   [course] Pressé                         le nom affiché (« RÈGLE DU JOUR : PRESSÉ »)
#   texte     | Tu pars plus vite...        la phrase de la fenêtre du jour
#   objets    | Esquive 1, Ressort 1        les équipements imposés, avec leur niveau (ce que le joueur porte ne
#                                           compte pas). Leur nom en français, comme dans la boutique : Aimant,
#                                           Double saut, Ressort, Esquive, Brise-tout, Sablier, Bottes de métal,
#                                           Gemmes dispersées, Dernier élan, Vol, Trèfle, Vitalité, Fana de TNT…
#   paliers   | 300 / 800 / 1600 / 2800     Bronze / Argent / Or / Légende, en mètres. Une course dure a des
#                                           paliers plus courts ; repère d'une journée normale : 400/1000/2000/3500.
#   vitesse   | 1.3                         départ et accélération multipliés (1 = normal, 1.3 = 30 % plus vite)
#   decor     | cite                        toute la course dans ce décor : foret, cite, donjon (pitons : seulement
#                                           si le Vol est imposé). Sans cette ligne, les décors s'enchaînent.
#   coeurs    | 1                           le nombre de cœurs (sans cette ligne : ceux du joueur)
#   montures  | non                         aucune monture sur le chemin
#   obstacles | araignees, volants          seulement ces dangers-là (les autres ne viennent pas). Familles :
#                                           herissons, araignees, volants, rondins. Les plates-formes, pentes et
#                                           pièces restent toujours.
#   poids     | 2                           (facultatif) chances d'être tirée : 2 = deux fois plus souvent, 0 = jamais
#   date      | 2026-12-25                  (facultatif) cette course ce jour-là, à la place du tirage
#
# Les lignes qui commencent par # sont ignorées. Réexporte le jeu pour voir tes changements.
# Les récompenses des paliers sont les mêmes pour toutes les courses : section [recompenses], tout en bas.
# ──────────────────────────────────────────────────────────────────────────────────────────────────────────
